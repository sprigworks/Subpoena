# Code of conduct

Be direct, be decent, and stay on the work.

No harassment, no personal attacks, and no posting of someone else's private
information.

To report a conduct problem privately, email hello@sprig.works. Reports are
read by the SprigWorks maintainers and kept confidential. Security reports go
to the same address or through private vulnerability reporting, never to an
issue.

SprigWorks maintains this repository. We may edit or remove comments and
contributions that break this.
